## The idea

Training an image model usually means uploading data to a server. I built Teachable Machine for low-resource settings: you show it a handful of photos per class, and the model trains right on your device with TensorFlow.js.

## How it works

Pick your classes, add a few images to each, and train. Predictions run live in the browser, so you can see straight away whether the model learned what you meant. The interface is built in React, with Supabase behind it.
